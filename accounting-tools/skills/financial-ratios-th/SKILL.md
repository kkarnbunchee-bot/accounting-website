# รายงานอัตราส่วนทางการเงิน

## Workflow
1. รับงบการเงิน 2 ปี แปลงเป็น CSV รูปแบบเดียวกับ skill `cash-flow-statement-th` (ใช้ไฟล์เดียวกันได้)
2. รัน:
   ```bash
   python scripts/thai_acct_reports.py ratios fs.csv --company "ชื่อบริษัท" -o ratios.xlsx
   python scripts/thai_acct_reports.py ratios fs.csv --average -o ratios-avg.xlsx   # ใช้ยอดเฉลี่ยปีล่าสุด
   ```
3. ตรวจบรรทัด "ตรวจสอบ: สินทรัพย์ − (หนี้สิน + ส่วนของผู้ถือหุ้น)" ต้องเป็น 0 ทั้งสองปี ไม่เช่นนั้นหยุดและแจ้งผู้ใช้
4. เขียนบทวิเคราะห์: จุดแข็ง 3 ข้อ, จุดที่ต้องระวัง 3 ข้อ, ข้อเสนอแนะ — เชื่อมกับงบกระแสเงินสดและรายงานอายุลูกหนี้/เจ้าหนี้

## สูตร
| อัตราส่วน | สูตร |
|---|---|
| Current / Quick / Cash | สินทรัพย์หมุนเวียน ÷ หนี้สินหมุนเวียน / (เงินสด+ลูกหนี้สุทธิ) ÷ หนี้สินหมุนเวียน / เงินสด ÷ หนี้สินหมุนเวียน |
| AR turnover, DSO | รายได้ ÷ ลูกหนี้สุทธิ, 365 ÷ AR turnover |
| Inventory turnover, DIO | ต้นทุนขาย ÷ สินค้า, 365 ÷ Inv turnover |
| AP turnover, DPO | ต้นทุนขาย ÷ เจ้าหนี้ (ใช้แทนยอดซื้อ), 365 ÷ AP turnover |
| Cash cycle | DSO + DIO − DPO |
| D/E, Debt ratio, Interest coverage | หนี้สินรวม ÷ ส่วนผู้ถือหุ้น, หนี้สินรวม ÷ สินทรัพย์รวม, EBIT ÷ ดอกเบี้ยจ่าย |
| GPM, EBIT margin, NPM, ROA, ROE | ÷ รายได้ / ÷ สินทรัพย์รวม / ÷ ส่วนของผู้ถือหุ้น |

## ข้อกำหนด
- ระบุฐาน (ยอดสิ้นปี/ยอดเฉลี่ย) ทุกครั้ง · ทศนิยม 2 ตำแหน่ง
- เกณฑ์ "ดี/ไม่ดี" เป็นแนวทางทั่วไป ต้องเทียบอุตสาหกรรม ห้ามสรุปเกินข้อมูล
