# รายงานอายุลูกหนี้

## Workflow
1. รับรายการเอกสารค้างรับ (export จากโปรแกรมบัญชี เช่น FlowAccount/Express หรือไฟล์ Excel) + วันที่รายงาน + ยอด GL
   - ถ้ามี FlowAccount MCP สามารถดึง AR aging/outstanding invoices มาตรวจเทียบได้
2. แปลงเป็น CSV คอลัมน์: `customer_code,customer_name,doc_no,doc_date,due_date,amount,paid,salesperson,remark` (วันที่ YYYY-MM-DD ค.ศ.)
   - ไม่มี due_date → คำนวณจาก doc_date + เครดิตเทอม และแจ้งข้อสมมติ
3. รัน:
   ```bash
   python scripts/thai_acct_reports.py ar-aging ar.csv --as-of 2026-10-31 --gl 2053500 \
       --rates 0,1,5,10,25,50,100 --company "ชื่อบริษัท" -o ar-aging.xlsx
   ```
4. ตรวจผล: ผลต่างกับ GL, ยอดติดลบ (ใบลดหนี้ยังไม่ตัดชำระ), เอกสารลงวันที่หลังวันรายงาน
5. สรุป: ยอดค้างรวม, % เกินกำหนด, ลูกหนี้เกิน 90 วันรายตัว + แนวทางติดตาม, ค่าเผื่อฯ ที่ควรมีเทียบยอดในบัญชี → เสนอรายการปรับปรุงถ้าจำเป็น

## ข้อกำหนด
- ช่วงอายุ: ยังไม่ถึงกำหนด, 1-30, 31-60, 61-90, 91-180, 181-365, >365 วัน (ครบกำหนดวันนี้ = ยังไม่ถึงกำหนด)
- อัตราค่าเผื่อฯ เป็นนโยบายบริษัท — ค่าเริ่มต้นเป็นเพียงตัวอย่าง ต้องให้ผู้ใช้ยืนยัน
- ภาษี: ค่าเผื่อหนี้สงสัยจะสูญไม่เป็นรายจ่ายทางภาษี (ม.65 ตรี (1)) การตัดหนี้สูญต้องเข้าเงื่อนไขกฎกระทรวง ฉบับที่ 186 (พ.ศ. 2534)
- วันที่แสดงผลเป็น พ.ศ. รูปแบบ DD/MM/YYYY ตัวเลขทศนิยม 2 ตำแหน่ง
- ห้ามเดาข้อมูล รายการที่อ่านไม่ได้ให้ลิสต์ไว้
