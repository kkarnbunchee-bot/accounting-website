# รายงานภาษีซื้อ

## Workflow
1. รับข้อมูลใบกำกับภาษีซื้อ (CSV/Excel หรือข้อมูลที่สกัดจาก PDF) + เดือนภาษี + เลขผู้เสียภาษีบริษัท
2. แปลงเป็น CSV: `doc_date,tax_invoice_no,vendor_name,vendor_tax_id,branch,description,amount,vat`
   - `branch`: "สำนักงานใหญ่" หรือเลขสาขา 5 หลัก · `description` ใช้ตรวจภาษีซื้อต้องห้าม
3. รัน:
   ```bash
   python scripts/thai_acct_reports.py vat vat.csv --month 2026-10 --company-tax-id 0999900001135 \
       --company "ชื่อบริษัท" --branch "สำนักงานใหญ่" --rate 7 -o purchase-vat.xlsx
   ```
4. ทบทวนชีต "ตรวจสอบ" ทุกรายการที่ "ตัดออก" อธิบายให้ผู้ใช้ และเสนอการแก้ไข (ขอใบกำกับใหม่, ยื่นในเดือนถัดไป, บันทึกเป็นค่าใช้จ่าย)
5. สรุปยอดที่ยกไปกรอก ภ.พ.30 (ยอดซื้อที่มีสิทธิ์นำภาษีซื้อมาหัก และภาษีซื้อเดือนนี้)

## กฎการตรวจ (สคริปต์ทำอัตโนมัติ + ต้องใช้วิจารณญาณเพิ่ม)
| ตรวจ | เกณฑ์ |
|---|---|
| เลขผู้เสียภาษี | 13 หลัก ผ่าน check digit mod 11 |
| VAT | = มูลค่า × อัตรา ± 1 บาท |
| ซ้ำ | ผู้ขาย + เลขที่ใบกำกับเดียวกัน |
| ระยะเวลา | เดือนที่ออกใบกำกับ ถึง 6 เดือนถัดไป (ม.82/3) |
| ต้องห้าม (ม.82/5) | ค่ารับรอง, รถยนต์นั่ง/รถโดยสารไม่เกิน 10 คน, ใบกำกับอย่างย่อ, ใบกำกับข้อความไม่ครบ, ไม่เกี่ยวกับกิจการ |

สคริปต์ตรวจภาษีซื้อต้องห้ามด้วยคำสำคัญเท่านั้น — **ต้องอ่านคำอธิบายทุกรายการซ้ำเอง** (เช่น ค่าน้ำมันรถยนต์นั่ง ค่าซ่อมรถเก๋ง)
อัตรา VAT ให้ยืนยันตามพระราชกฤษฎีกาที่ใช้บังคับในเดือนภาษีนั้น ห้ามเดาตัวเลขที่อ่านไม่ชัด
