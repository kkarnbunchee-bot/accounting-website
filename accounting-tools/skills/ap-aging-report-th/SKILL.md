# รายงานอายุเจ้าหนี้

## Workflow
1. รับรายการใบแจ้งหนี้ค้างจ่าย + วันที่รายงาน + ยอด GL (ถ้ามี FlowAccount MCP ใช้ AP aging/outstanding payments เทียบได้)
2. แปลงเป็น CSV: `vendor_code,vendor_name,doc_no,doc_date,due_date,amount,paid,remark`
3. รัน:
   ```bash
   python scripts/thai_acct_reports.py ap-aging ap.csv --as-of 2026-10-31 --gl 523190 --company "ชื่อบริษัท" -o ap-aging.xlsx
   ```
4. ตรวจ: ผลต่างกับ GL, ใบแจ้งหนี้ซ้ำ, ยอดติดลบ (จ่ายเกิน/ใบลดหนี้), รายการโต้แย้ง
5. สรุป: ยอดค้างจ่าย, เกินกำหนด, ประมาณการเงินสดจ่าย (เกินกำหนด / ภายใน 7 วัน / ภายใน 30 วัน), ลำดับความสำคัญการจ่าย

## ข้อกำหนด
- ช่วงอายุเดียวกับรายงานลูกหนี้ เพื่อเทียบกันได้
- เตือนการหักภาษี ณ ที่จ่ายเมื่อจ่ายค่าบริการ/ค่าเช่า/ค่าขนส่ง (ภ.ง.ด.3/53) — อัตราขึ้นกับประเภทเงินได้ ต้องตรวจตามคำสั่งกรมสรรพากร ท.ป.4/2528
- รายการค้างนานผิดปกติ (>180 วัน) ให้พิจารณาว่ายังเป็นภาระผูกพันจริงหรือควรขอยืนยันยอด
- วันที่แสดง พ.ศ. ห้ามเดาข้อมูล
