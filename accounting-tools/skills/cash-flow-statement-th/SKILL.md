# งบกระแสเงินสด (วิธีทางอ้อม)

## Workflow
1. **รับข้อมูล** — งบแสดงฐานะการเงิน 2 ปี, งบกำไรขาดทุนปีปัจจุบัน, ข้อมูลเพิ่มเติม (ค่าเสื่อม, หนี้สงสัยจะสูญ, ซื้อ/ขายสินทรัพย์, ดอกเบี้ยจ่ายจริง, ปันผล)
   ถ้าข้อมูลเพิ่มเติมไม่มี ให้ **ถามผู้ใช้** ห้ามเดา
2. **แปลงเป็น CSV มาตรฐาน** คอลัมน์ `code,section,item,y<ปีก่อน>,y<ปีนี้>` (ปี ค.ศ.) โดยใช้รหัส:
   - BS: `BS_CASH, BS_AR (ก่อนหักค่าเผื่อ), BS_ALLOW (บวก), BS_INV, BS_PREPAID, BS_PPE (ราคาทุน), BS_ACCDEP (บวก), BS_AP, BS_ACCRUED, BS_TAXPAY, BS_STLOAN, BS_LTLOAN, BS_CAPITAL, BS_RE`
   - PL: `PL_REV, PL_COGS, PL_OTHINC, PL_SGA, PL_INT, PL_TAX`
   - SUP: `SUP_DEP, SUP_BADDEBT, SUP_GAIN, SUP_PPE_BUY, SUP_PPE_PROCEEDS, SUP_INT_PAID, SUP_DIV`
   บัญชีอื่นที่ไม่มีรหัส ให้รวมเข้ารหัสที่ลักษณะใกล้เคียงที่สุด และ **แจ้ง mapping ให้ผู้ใช้ยืนยัน**
3. **รันสคริปต์**
   ```bash
   python scripts/thai_acct_reports.py cashflow fs.csv --company "ชื่อบริษัท" -o cashflow.xlsx
   ```
4. **อ่านผลตรวจสอบ** — ทุกข้อในชีต "ตรวจสอบ" ต้องผ่าน ถ้าไม่ผ่าน ให้อธิบายสาเหตุที่เป็นไปได้ (เช่น มีตัดหนี้สูญ, ปันผลค้างจ่าย, เช่าซื้อสินทรัพย์ที่ไม่ใช่เงินสด) **ห้ามแก้ตัวเลขเพื่อให้ลงตัว**
5. **สรุปให้ผู้ใช้** — CFO/CFI/CFF, Free Cash Flow, ข้อสังเกต 3–5 ข้อ

## หลักวิชาการที่ต้องยึด
- ลูกหนี้ใช้ยอดก่อนหักค่าเผื่อ แล้วบวกกลับหนี้สงสัยจะสูญเป็นรายการไม่ใช่เงินสด
- ภาษีจ่าย = ภาษีค้างจ่ายต้นงวด + ค่าใช้จ่ายภาษี − ภาษีค้างจ่ายปลายงวด
- ดอกเบี้ยจ่ายจัดในกิจกรรมดำเนินงาน (นโยบายนี้ต้องใช้สม่ำเสมอ) ปันผลจ่ายจัดในกิจกรรมจัดหาเงิน
- กิจกรรมลงทุน/จัดหาเงินแสดงแบบ gross ไม่หักกลบ
- รายการไม่ใช่เงินสด (เช่าซื้อ, แปลงหนี้เป็นทุน) ไม่แสดงในงบ แต่เปิดเผยในหมายเหตุ
- TFRS for NPAEs ไม่บังคับจัดทำงบกระแสเงินสด; PAEs ใช้ TAS 7
