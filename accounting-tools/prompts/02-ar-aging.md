# Prompt 2 — รายงานอายุลูกหนี้ (AR Aging)

> แนบรายการใบแจ้งหนี้ค้างรับ (export จากโปรแกรมบัญชี) · ไฟล์ตัวอย่าง: `sample-data/ar_open_invoices.csv`

```text
บทบาท: คุณเป็นนักบัญชีอาวุโสด้านลูกหนี้และเครดิต
งาน: จัดทำ "รายงานวิเคราะห์อายุลูกหนี้" ของ [ชื่อบริษัท] ณ วันที่ [DD/MM/25XX]

ข้อมูลที่แนบ: รายการเอกสารค้างรับ คอลัมน์ รหัสลูกค้า, ชื่อลูกค้า, เลขที่เอกสาร, วันที่เอกสาร, วันครบกำหนด, ยอดเงิน, ยอดรับชำระแล้ว, พนักงานขาย, หมายเหตุ
ยอดลูกหนี้ตามบัญชีแยกประเภท (GL) ณ วันเดียวกัน: [จำนวนเงิน]

กติกา:
1. ยอดคงค้าง = ยอดเงิน − รับชำระแล้ว ตัดรายการที่คงค้าง 0 ออก
2. นับอายุจาก "วันครบกำหนด" ถึงวันที่รายงาน (ถ้าไม่มีวันครบกำหนด ใช้วันที่เอกสาร + เครดิตเทอม และระบุว่าใช้ข้อสมมตินี้)
3. ช่วงอายุ: ยังไม่ถึงกำหนด | 1-30 | 31-60 | 61-90 | 91-180 | 181-365 | เกิน 365 วัน
4. ใบลดหนี้/ยอดติดลบ ให้แสดงแยกและแจ้งให้ตัดชำระกับใบแจ้งหนี้ที่เกี่ยวข้อง
5. คำนวณค่าเผื่อหนี้สงสัยจะสูญตามอัตรานโยบาย: [0%,1%,5%,10%,25%,50%,100%] (หรือใช้อัตราที่บริษัทกำหนด)
6. กระทบยอดรวมกับ GL ถ้ามีผลต่างให้แสดงตัวเลขและสาเหตุที่เป็นไปได้

ผลลัพธ์:
- ตารางสรุปรายลูกค้า × ช่วงอายุ พร้อมรวมและ % ต่อยอดรวม
- ตารางรายละเอียดรายเอกสาร (วันที่แบบ พ.ศ. DD/MM/YYYY)
- ไฮไลต์ลูกหนี้เกิน 90 วัน + ข้อเสนอแนะการติดตามรายราย (โทร/หนังสือทวงถาม/ระงับเครดิต/ดำเนินคดี)
- KPI: ยอดค้างรวม, % เกินกำหนด, ยอดเกิน 90 วัน, ค่าเผื่อฯ ที่ควรตั้งเทียบกับยอดในบัญชี
- ข้อควรระวังทางภาษี: การตัดหนี้สูญเป็นรายจ่ายต้องเข้าเงื่อนไขกฎกระทรวง ฉบับที่ 186 (พ.ศ. 2534) และค่าเผื่อหนี้สงสัยจะสูญไม่ถือเป็นรายจ่ายทางภาษี (ม.65 ตรี (1))
- ห้ามเดาข้อมูล ถ้าวันที่หรือยอดอ่านไม่ได้ให้ระบุรายการที่ต้องตรวจ
```
